# artproducktion.com โฉมใหม่ — เว็บ static (ร่าง v1 · 6 ต.ค. 2569)

เว็บ HTML ธรรมดา ไม่มีขั้นสร้างหน้า · ขึ้น GitHub Pages ตรง ๆ

## แก้อะไร แก้ที่ไหน
| อยากแก้ | ไฟล์ |
|---|---|
| ข้อความหน้าแรก (คำขวัญ · เราคือใคร · การ์ด 4 ส่วน · ลิงก์ท้ายหน้า) | `index.html` |
| สี · ฟอนต์ · ขนาดตัวหนังสือ | `assets/css/site.css` บรรทัดบนสุด `:root` (แก้ที่เดียวเปลี่ยนทั้งเว็บ) |
| เมนูแถบบน · ปุ่มภาษา · ท้ายหน้า | `assets/js/site.js` ตัวแปร `MENU` และ `UI` |
| หน้าแต่ละส่วน | `art/` `photo/` `tarot/` `books/` `links/` (ตอนนี้เป็นหน้าว่างรอทำ) |
| ฉบับอังกฤษ | โฟลเดอร์ `en/` โครงเดียวกัน · หน้าไหนทำแล้วใส่ชื่อใน `EN_PAGES` ใน `site.js` ปุ่มภาษาจะชี้ไปเอง |
| รูปหน้าแรก | `assets/img/home/` |

## กฎ
- ลิงก์ในหน้าใช้แบบสัมพัทธ์เสมอ (`../tarot/` ไม่ใช่ `/tarot/`) เพราะตอนดูตัวอย่างเว็บอยู่ใต้ `/artproducktion-site/` แต่ของจริงอยู่ที่ราก
- ทุกหน้าต้องมี `<meta charset="utf-8">` · แถบบนเป็น `<header class="topbar" data-site-header>` ท้ายหน้าเป็น `<footer class="footer" data-site-footer>` แล้ว `site.js` เติมให้เอง
- `<body data-section="art|photo|tarot|books|links|home">` บอกว่าหน้านี้อยู่ส่วนไหน (เมนูจะไฮไลต์ + สีแทรกของส่วนจะเปลี่ยนเอง)
- ตอนสลับโดเมนต้องคัดลอก `cards/` และ `downloads/` จาก repo hub มาไว้ที่รากของ repo นี้ด้วย (Seer's Note · โต๊ะเปิดไพ่ · อีเมลส่งหนังสือ ชี้มาที่นั่น)
